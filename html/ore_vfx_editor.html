Emitter파티클 수·수명·ID 인코딩

Shape · 3D 배치

Shape (Image Contour)이미지 업로드 → 밝기/알파/RGB 채널 기준 외곽선 추출 → Elliptic Fourier Descriptors로 근사 수식 생성. x/y/z 출력 — 로고·글자·실루엣 모양으로 파티클을 배치

Noise · 실시간 미리보기 포함

Noise 3DPerlin/Simplex/Voronoi/FBM 선택 가능. x/y/z→노이즈값 n. 연결 위치 자동 역추적(offset=1회, tint/size=파티클마다 재계산). 노드 안에서 패턴을 흑백 이미지로 바로 확인
Curl Noise발산 없는(비압축) 벡터장 노이즈 — fx/fy/fz 힘 출력. 연기·불·소용돌이 같은 유체형 터뷸런스 움직임에 사용. flow 옵션으로 패턴이 시간에 따라 흐르게 가능. 미리보기는 흐름 화살표(벡터장)로 표시
Vector Field (Image)이미지를 업로드해 그리드로 구운 커스텀 벡터장 — fx/fy 힘 출력. 밝기 그래디언트/마스크 경계/RGB 플로우맵 3가지 방식 지원. 로고·문양·커스텀 형태로 파티클을 흐르게 할 때 사용
Turbulence (Curl FBM)Curl Noise를 여러 옥타브로 겹친 다중 스케일 난류 — fx/fy/fz 힘 출력. Houdini POP Turbulence, Unity VFX Graph "Turbulence"와 동일 개념. 큰 소용돌이 위에 작은 디테일이 겹쳐 연기·구름처럼 복잡한 흐름을 만듦. flow 옵션으로 시간에 따라 흐르게 가능

Force Field · 벡터장 (Unity/Unreal 표준)

Vortex Field축 중심 회전 소용돌이 흐름(점성 결합 + 구심 가속) — fx/fy/fz 출력. Unity VFX Graph "Vortex", Unreal Niagara "Vortex Velocity Force"와 동일 개념. 태풍·회오리·빨려들어가는 소용돌이 연출. pulse 옵션으로 세기가 주기적으로 맥동하게 가능
Attractor / Point Force한 점을 향한 인력(+)/척력(-) 힘 — fx/fy/fz 출력. Unity "Sphere Attraction", Niagara "Point Attraction Force"와 동일. 폭발 흡수·수집 이펙트·자석 연출. pulse 옵션으로 세기가 심장박동처럼 맥동하게 가능
Directional Force일정한 방향으로 미는 힘(중력/바람) — fx/fy/fz 출력. Niagara "Gravity Force"/"Wind Force"와 동일. 낙하·바람에 날리는 효과의 기본 힘. gust 옵션으로 세기가 시간에 따라 변하는 돌풍 표현 가능
Wind Zone영역(박스/구) 안에서만 부는 국소 바람 — fx/fy/fz 출력. Unity "Wind Zone", Niagara의 볼륨 제한 Wind Force와 동일. 특정 구역에서만 바람이 부는 연출(창틈 바람, 국소 돌풍)에 사용. gust 옵션으로 세기 변조, turbulence와 함께 쓰면 방향·세기 모두 흔들리는 자연스러운 돌풍
Wall · 벽박스(min/max) 벽에 부딪혀 튕기는 위치 보정 — 입력 x/y/z → 출력 x/y/z. 벽마다 마찰력·반동(슬라임 블록처럼) 지정, 눈 아이콘으로 3D 프리뷰에 벽 표시. Shape/Noise 등의 위치 출력과 Output offset 사이에 끼워 쓰세요.
Drag / Damping항력 계수 하나를 출력합니다(Bedrock linear_drag_coefficient 기준, Niagara "Drag Force"와 같은 개념). 참고: 이 에디터는 파티클을 엔진 물리가 아니라 수식으로 움직이므로 Output에 drag 소켓이 없습니다 — 값은 Formula 같은 다른 노드에 숫자로 연결해 쓰세요
Buoyancy온도차(T-T_ambient) 기반 부력 — fx/fy/fz 출력. Houdini pop buoyancy와 동일 개념. 뜨거운 연기/불이 위로 뜨는 움직임. temperature 미연결시 emitter_age(이미터 전역 경과시간) 또는 particle_age(개별 파티클 생존시간, v5부터 유효) 중 선택해 자동 식음

Math · 커스텀 수식

Formula자유 수식 → Molang 자동변환. t(시간) 입력 소켓 포함 — Vortex/Attractor 등 다른 노드의 strength·radius에 연결해 시간 변조 가능
Constant (상수)상수값 하나를 그대로 출력 — Accumulate의 in(초당 증가량)·init(초기값), Formula 입력 등에 연결해 쓰는 값 노드
Remap입력값을 [inMin,inMax] 구간에서 [outMin,outMax] 구간으로 재매핑(clamp 옵션) — Unity/Houdini의 Remap/Fit 노드와 동일. 노이즈나 벡터장 세기를 원하는 범위로 손쉽게 조정
Dissipation반감기(half-life) 기반 지수 감쇠 → out 출력. 연기 밀도·온도·알파가 시간이 지나며 옅어지는 현상(D_t+1=D_t·(1-α·Δt))을 표현. tint.a나 size에 연결하면 자연스럽게 사라지는 연기/불씨 효과. 자동 시간축은 emitter_age(전역 경과시간)/particle_age(개별 생존시간, v5부터 유효) 중 선택 가능
Accumulate (누적)id·시간에서 매 프레임 다시 계산하는 상태 없는 누적 노드 — out = init + ∫in dt (변수 공유 문제 없음). 회전각·이동거리처럼 "지금까지 쌓인 값"에 사용. clamp/wrap/reset 지원

Color · Over-Life

Color Gradient여러 색상 정지점을 t(0~1)로 보간 → r/g/b 출력. 실제 그라디언트 바를 눈으로 보며 편집(Unity/Houdini의 Gradient 노드와 동일한 개념)
Curve (Over-Life)파티클 수명(0~1) 기준 곡선 → 크기/알파 등에 연결. 그래프를 손가락으로 직접 그려서(포인트 추가/드래그) 커브 모양을 편집

Texture · UV

Flipbook UV텍스처 아틀라스(그리드)를 시간에 따라 순서 재생 — u/v/uv_size.w/uv_size.h 출력. Unity "Texture Sheet Animation"/Niagara "Sub UV"와 동일. Output의 uv 소켓에 바로 연결해 스프라이트 시트 애니메이션(폭발·불꽃·연기 프레임 재생)을 구현
Threshold / Dissolve입력값을 기준값과 비교해 0/1로 이진화(softness로 경계 부드럽게) — Shader Graph의 "Step"과 동일. Noise 3D 출력을 여기 연결하고 threshold를 Curve로 움직이면 노이즈 패턴을 따라 사라지는 dissolve 효과. 출력을 tint.a에 연결
