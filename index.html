BEDROCK VFX NODE EDITOR · v1.1.5

Build Minecraft Bedrock Edition particles with a node graph. Connect nodes, and ORE writes the Bedrock particle JSON (Molang) and a resource pack (.mcpack) for you.

Web editorNo install

Edit node graphs right in your browser, check them in the 3D preview, then export JSON or a .mcpack. Save your work to a file with 💾. Available in English and Korean.

Open the web editor →

Works best in an up-to-date browser such as Chrome or Edge. Works on PC and mobile.

MCP toolInstall on your PC

Lets AI apps such as Claude Desktop or Claude Code build and edit the same node graphs. It uses the same compiler as the web editor, and the results open in the web editor as they are.

  1. Install Node.js 20.3 or later
  2. Download the source ZIP, unzip it and run npm install in the mcp_tool folder
  3. Register mcp_tool/src/server.mjs in your AI app's settings
